# Knowledge Extractor — Releases

Este repositório guarda apenas as **versões publicadas** do Knowledge Extractor (aplicativo desktop).
O código-fonte fica em um repositório privado; aqui ficam os instaladores e os pacotes de atualização.

## Como baixar

Acesse a aba [Releases](https://github.com/ai-driven-projects/knowledge-extractor-releases/releases)
e baixe o arquivo da versão mais recente para o seu sistema.

## Atualização automática

O aplicativo consulta este repositório para saber se há uma versão nova e, quando houver,
baixa e instala a atualização. Não é preciso voltar aqui a cada versão.
